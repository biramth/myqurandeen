# Code de conduite

## Notre engagement

Ce projet etudie l'Islam de maniere academique et sourcee. Nous nous
engageons a faire de la participation a ce projet une experience respectueuse
pour tous, quels que soient l'ecole de pensee, le courant, le niveau de
connaissance religieuse, la nationalite, le genre ou l'origine.

## Nos regles

Comportements attendus :

- Rester factuel et sourcer toute affirmation religieuse ou historique.
- Presenter les divergences (fiqh, tafsir, theologie) de maniere descriptive,
  sans les hierarchiser ni les qualifier de fausses/vraies.
- Faire preuve de courtoisie dans les discussions techniques et editoriales.
- Accepter la critique constructive sur le code comme sur le contenu.

Comportements inacceptables :

- Polemique, proselytisme ou attaque envers une ecole, un courant ou une
  personne.
- Contenu inventé presenté comme une source fiable.
- Harcelement, propos discriminatoires ou insultes, sous quelque forme que
  ce soit.

## Application

Les violations peuvent etre signalees en ouvrant une issue confidentielle ou
en contactant les mainteneurs du depot. Les mainteneurs se reservent le droit
de retirer, modifier ou rejeter toute contribution ne respectant pas ce code,
et de suspendre temporairement ou definitivement l'acces d'un contributeur.

## Perimetre

Ce code de conduite s'applique dans tous les espaces du projet (issues, pull
requests, discussions) ainsi que dans toute communication publique effectuee
au nom du projet.
